Roupa / Segurando (por slot)

Cada slot sorteia 1 item entre as alternativas cadastradas nele (nunca nasce com todas juntas — é assim que o motor do jogo funciona de verdade). Mais alternativas = mais variedade no spawn. Clica em "Adicionar item" pra escolher com imagem — o slot certo já é achado/criado sozinho (sugestão por categoria).

Outros slots (nome digitado — Vest/Back/Hands/Gloves/Headgear/Eyewear/Mask/Armband são comuns no jogo, mas só Body/Legs/Feet foram confirmados contra o seu arquivo real)

Mochila / bolso (pacotes)

Cada pacote é um grupo de itens que nascem juntos (ex: 1 curativo + 1 chemlight + comida). O jogo escolhe 1 pacote entre os cadastrados.
