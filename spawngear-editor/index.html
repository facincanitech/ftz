Roupa (por slot)

Cada slot sorteia UM item entre as opções listadas — pra roupa aleatória de verdade, cadastra vários itens no mesmo slot. Clica em "Adicionar item" pra escolher com imagem e o slot certo já é achado/criado sozinho (sugestão por categoria — confere se veio certo, pode corrigir digitando o nome do slot na mão se precisar).

Mochila / bolso (pacotes)

Cada pacote é um grupo de itens que nascem juntos (ex: 1 curativo + 1 chemlight + comida). O jogo escolhe 1 pacote entre os cadastrados.
