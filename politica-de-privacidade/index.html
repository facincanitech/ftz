Política de Privacidade

Última atualização: agosto de 2026

Esta política descreve quais dados o FTZ Bot ("Serviço", "Bot"), operado pela Facincani Tech, coleta e como eles são usados. Ao usar o Bot ou o site do Serviço, você concorda com esta política.

1. Dados que coletamos

DadoOrigemPor quê
ID de usuário e servidor do DiscordDiscordIdentificar quem interage com o Bot e em qual servidor

2. Como usamos os dados

  • Operar as funcionalidades do Bot (economia, loja, killfeed, radar, agendamento, anti-cheat);
  • Processar pagamentos via Mercado Pago;
  • Diagnosticar problemas técnicos e melhorar o Serviço.

Não vendemos nem compartilhamos esses dados com terceiros para fins de marketing.

3. Onde os dados ficam

Os dados operacionais (jogadores, economia, eventos, logs processados) ficam armazenados num banco Postgres gerenciado (Supabase). Tokens de API de terceiros (Nitrado) ficam apenas na configuração do servidor do Bot, não são expostos a outros usuários.

4. Retenção

Dados de jogador (economia, ranking, posição) são mantidos enquanto o servidor estiver ativo no Bot. Dados de pagamento seguem o período exigido pela legislação fiscal aplicável. Você pode solicitar remoção de dados específicos entrando em contato (sujeito a limitações técnicas do log do próprio jogo, que não controlamos).

5. Terceiros envolvidos

  • Discord — hospeda a interface onde o Bot opera;
  • Nitrado — hospeda o servidor de jogo e fornece os logs consumidos pelo Bot;
  • Mercado Pago — processa pagamentos, não temos acesso a dados completos de cartão;
  • Supabase — hospeda o banco de dados do Bot.

6. Seus direitos

Você pode solicitar acesso, correção ou remoção dos seus dados pessoais (ex: desvincular sua gamertag) entrando em contato pelos canais do Serviço.

7. Contato

Dúvidas sobre esta política: contato via Discord do desenvolvedor.
